We provide protein sequences data in Data folder. Most of them are ready to use for node-wise regression. The sample weights of data are calculated by sample_weight.m.

Some of RData are provided in the raw data form limited by the available file size. If that, please use PreProcessData.R to process the data to the forms that are suitable for nodewise regression.

Simulated data can be generated by using Gibbs_Sampler.R with different settings. The generated data should also be pre-processed and applied the nodewise regression model.
